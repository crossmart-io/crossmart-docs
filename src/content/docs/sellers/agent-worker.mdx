Agent Worker is an AI agent you chat with inside Crossmart. You ask it to do something, such as
"Fix my failed eBay listings", and it looks up what it needs and proposes the changes. Nothing
changes until you approve.

You don't need to set up your own AI agent to use it. If you do use one through
[MCP](/agents/), Agent Worker works with the same tools and the same limits.

## Open it

- **Channel map:** click **Ask Agent Worker** at the top of the page. On a store with failed
  listings, **Fix with Agent Worker** opens it with a message ready to send ("Fix the failed
  listings on …"). Edit it or press send.
- **A product's page:** the product's **Channel map** card has its own **Ask Agent Worker**
  button. There, "this product" means that product.
- **Anywhere:** the **Agent Worker** button in the header, or <kbd>Cmd</kbd>+<kbd>J</kbd>
  (<kbd>Ctrl</kbd>+<kbd>J</kbd> on Windows and Linux).

It opens as a panel on the right. Your earlier conversations are under **Conversations**, and
**New conversation** starts a fresh one. Only you see your conversations.

## What it can do

Agent Worker works with your catalog, stock, stores and orders. For example:

- "Which products are low on stock?"
- "Fix my failed eBay listings"
- "Publish the Linen Shirt to my Outlet store"
- "Rewrite titles for Etsy"
- "Add 20 units of the M size, stock received"
- "Change the price of the M size to $43"

It can find products, stock, listings, orders and reports, edit products and prices, adjust
stock, add products to stores and take them off, and ask Crossmart's AI for content. It can also
answer questions about Crossmart itself.

It can't connect or disconnect stores, manage members or API keys, change settings or billing, or
manage webhooks. Do those yourself in the dashboard.

## Reads run at once, changes wait for you

When Agent Worker only needs to look something up, it does so right away and shows a short line
for each step, such as "List stock · 6 found".

When it wants to change something, it stops and shows a **Review the changes** card. Each change
says what it does in plain words, which product and store it touches, and the values **Now** and
**After**, such as "Price (M): $48.00 → $43.00". Longer text, such as a description, shows which
words change.

- Tick the changes you want and click **Approve selected**. The ones you leave unticked are
  rejected.
- **Reject all** turns them all down.
- If you send a new message instead, the changes still waiting are dropped.

Approved changes run with your permissions at that moment, and each one shows whether it was
applied or failed. Agent Worker then carries on with the results. Every change is recorded in
**Activity** as "Agent Worker" on your behalf.

**Stop** ends what Agent Worker is doing. Closing the panel stops it too.

## Extra confirmation for risky changes

Some changes carry a red badge and need a second step. Before **Approve selected** works, you
tick a box such as "I understand this deletes".

| Badge              | When                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------- |
| **Deletes**        | The change deletes something or takes it off sale                                     |
| **Changes prices** | The change sets a price or compare-at price that differs from today's                 |
| **Many items**     | The change touches more than 5 items, or your approval publishes more than 5 listings |

If text Agent Worker read in that step looks like instructions to an AI (for example, a product
description that says "ignore previous instructions"), the card warns you: "Text read in this
turn looked like instructions; review carefully". Agent Worker treats what it reads as data, and
it can still only propose; you decide.

## AI credits

Every time Agent Worker calls the AI model, it uses one AI credit, the same as Crossmart's other
AI features. One message can take several calls, because Agent Worker calls the model again after
each lookup. A message makes at most 8 calls.

- If you have no credits left, Agent Worker can't start.
- If credits run out partway through, it stops and keeps what it already did.

Your credits are under **Settings → Plan & usage**.

## Who can use it

Owners, Admins and Editors can use Agent Worker. Approvers and Viewers can't, and don't see its
buttons. A custom role can include it with the `agent_worker:use` permission (see
[Roles and permissions](/developers/permissions/)).

Agent Worker can never do more than your role allows. If your role can't make a change, the change
is refused when you approve it, and the card says so.

## When it is limited

- **A sandbox account** (one an AI agent created for you that you haven't claimed yet) can't use
  Agent Worker. Claim the account first.
- **A read-only account** (when the subscription isn't paid) can still chat with Agent Worker and
  look things up, but it can't propose changes.
- **One message at a time** per conversation. Wait for the answer, or press **Stop**.

Conversations are kept for 180 days after the last message, then deleted.

<Aside title="The same tools as the MCP server">
  Agent Worker uses the same tools as Crossmart's [MCP server](/developers/mcp/), and every call
  goes through the same API, with the same checks and the same activity log. The difference is that
  Agent Worker never makes a change on its own: every change waits for your approval.
</Aside>
