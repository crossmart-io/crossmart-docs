# crossmart-docs

The documentation site for [Crossmart](https://crossmart.io), the open-source multichannel
platform for sellers and their AI agents, served at
[docs.crossmart.io](https://docs.crossmart.io).

Built with [Starlight](https://starlight.astro.build) (Astro), as decided in the backend
repository's ADR 0013.

## Develop

Requires Node.js 22.23+ (see `.nvmrc`) and pnpm.

```bash
pnpm install
pnpm dev          # http://localhost:4321
pnpm format       # Prettier
pnpm build        # type check, build into dist/ and validate links between pages
pnpm check:links  # after a build: check every internal link and anchor in dist/
```

`pnpm build` fails on a broken link or anchor in the pages (`starlight-links-validator`).
`pnpm check:links` also covers the generated API reference, which that validator can't see. The
build also writes `llms.txt`, `llms-full.txt` and `llms-small.txt` for AI agents.

## Structure

| Path                           | What                                                     |
| ------------------------------ | -------------------------------------------------------- |
| `src/content/docs/`            | Pages, in Markdown or MDX; the path is the URL           |
| `src/content/docs/developers/` | The developer guide: API overview, quickstart, SDKs, MCP |
| `openapi/crossmart.json`       | Snapshot of the API's OpenAPI spec                       |
| `astro.config.mjs`             | Site config and the sidebar                              |
| `src/styles/theme.css`         | Brand colours on Starlight's theme variables             |

The developer guide follows `docs/developers/` and `sdks/*/README.md` in
[crossmart-io/crossmart](https://github.com/crossmart-io/crossmart). Change both together.

### API reference

The pages under `/developers/api/` are generated by
[starlight-openapi](https://github.com/HiDeoo/starlight-openapi) from `openapi/crossmart.json`.
After an API release, refresh the snapshot and commit it. When the spec names no `servers`,
the sync adds `https://api.crossmart.io` so code samples point at the real API.

```bash
pnpm openapi:sync                                                      # from api.crossmart.io
CROSSMART_OPENAPI_URL=http://localhost:3000/api/docs-json pnpm openapi:sync   # from a local API
```

## Deploy

The site is static. The `Dockerfile` builds it and serves `dist/` with nginx on `$PORT`
(`deploy/nginx.conf.template`), the same way as the marketing site.
